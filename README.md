# Unique Generation Outreach

Marketing site for Unique Generation Outreach (Vite + React), inspired by the Faith Framer template.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (default `http://127.0.0.1:5173`).

## Build

```bash
npm run build
npm run preview
```

## Content

Editable copy lives in `src/data/content.js`. Replace photo placeholders, contact details, and sample reflections when official assets arrive.
